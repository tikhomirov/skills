# Reader extensions — recipe map

Load these only after finding a concrete smell. They are **not** book chapters.

| Smell or task | Load extension recipe | Status |
|---|---|---|
| "Just in case" fallbacks, cascading path checks, AI guessing a second source of truth | `extensions/recipes/just-in-case.md` | Reader / author extension — not an official book chapter |

## Rules

- Prefer official `recipes/` when a book-derived recipe already covers the smell.
- When using an extension, say so explicitly in the answer.
- Do not invent a `content/0xx-*.md` book path for extension recipes.
