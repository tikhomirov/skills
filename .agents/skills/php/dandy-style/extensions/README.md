# Скиллы / главы от читателей (reader extensions)

**Статус:** пользовательские (читательские) дополнения к экосистеме Dandy Style.

Это **не** официальные главы книги «Денди-код» и **не** канонические рецепты автора книги.
Это расширение скилла `dandy-style`: идеи из практики, ревью и обратной связи читателей/разработчиков.

## Зачем отдельный раздел

Книга остаётся источником вдохновения, но материал устаревает. Скилл живёт дальше:
новые проблемы (в т.ч. от AI), новые решения. Официальные `recipes/` + `source-map.md`
держат связь с главами книги. Этот каталог — явный слой **дополнений**, чтобы агент
и человек не путали их с каноном книги.

## Как пользоваться

1. Сначала обычный поток: проблема → `recipe-map.md` → официальные рецепты.
2. Если запах совпал с записью в `extensions/recipe-map.md` — загрузи рецепт отсюда.
3. В ответах помечай рекомендацию как **читательское дополнение Dandy Style**, не как главу книги.

## Содержимое

| Id | Файл | Кратко |
|---|---|---|
| `just-in-case` | `recipes/just-in-case.md` | Один источник правды; без «на всякий случай», особенно когда AI угадывает |

Карта: `extensions/recipe-map.md`.

## Как добавить ещё

1. Положите рецепт в `extensions/recipes/<id>.md`.
2. Зарегистрируйте в `extensions/recipe-map.md`.
3. При необходимости добавьте строку в корневой `recipe-map.md` с путём `extensions/recipes/...`.
4. **Не** добавляйте вымышленную главу в `source-map.md` и **не** кладите файл в `recipes/` канона.
