# Obsidian Project Framework — быстрый старт

Агент ведёт задачи, документацию и память проекта в Obsidian. Ты обсуждаешь решения с агентом и перемещаешь задачи на канбане.

## 1. Установи

Нужны **Node.js 20+**, Git и **Obsidian 1.14+** с включённым Bases.

```bash
git clone https://github.com/tikhomirov/skills.git
cd skills
npm ci
npm link
skills-install obsidian obsidian-project-framework project-workshop improvement --global
```

Если репозиторий уже скачан, начни с `cd skills`. `npm link` добавляет команды фреймворка в PATH; `skills-install` устанавливает инструкции для агентов. При ошибке прав не запускай весь процесс через sudo: используй пользовательскую установку Node.js.

## 2. Попроси агента настроить проект

Открой **репозиторий своего приложения** в AI-ассистенте. Если он уже запущен, перезапусти сессию, чтобы обнаружить новые скиллы. Отправь:

> Используй project-workshop и obsidian-project-framework. Настрой документацию этого проекта в Obsidian. Хранилище: `/полный/путь/к/хранилищу`, имя проекта: `my-project`. Сначала изучи проект и существующие документы, затем согласуй со мной правила и модули. Не меняй код приложения. Перед заменой документов сделай резервную копию. Документацию модулей создавай только после моего явного разрешения.

**Замени путь и имя своими.** Хранилище — существующая папка, открытая в Obsidian, не папка исходников приложения. Агент задаст вопросы и создаст структуру; тебе не нужно вручную писать конфиги или изучать команды. Если агент не видит скиллы, укажи ему файлы `skills/obsidian-project-framework/SKILL.md` и `skills/project-workshop/SKILL.md` в скачанном репозитории.

## 3. Открой доску и работай

В Obsidian открой `Projects/my-project/Tasks/_Задачи.base`. Если в хранилище уже есть `Проекты/`, используется она. Начальные колонки: **Backlog → In Progress → Done**.

- Дай агенту поручение — он оформит задачу и сохранит результат.
- Перетаскивай карточки сам: перед продолжением агент выполняет `task sync`, сохраняя твой выбор.
- Статусы меняются по твоему запросу через короткий `_statuses.md`.
- Память и отчёты — в `_agents/`; решения — в `Решения/`.
- Скажи «архивируй завершённую задачу TASK-001» или «восстанови её» — архив хранит карточки и историю.

CLI самого Obsidian **включать не нужно**: наши команды работают с файлами. Отметка Done не означает, что тесты приложения прошли.

Справка: `obsidian-project-framework --help`. Проверки разработки: `make check && make test`. [Полная документация и другие скиллы](README.md).
