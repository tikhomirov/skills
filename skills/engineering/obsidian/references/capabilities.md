# Возможности

- Web viewer — встроенный; Web Clipper — расширение браузера.
- Sync и Publish — отдельные сервисы. Recovery не заменяет backup.
- Dataview, Tasks, Templater, Excalidraw, Map и сторонний Kanban — внешние плагины.

- Bases: table, cards, list, kanban (1.14+), filters, formulas, grouping, summaries.
- Canvas: визуальная схема, не база задач.
- Templates, Daily notes, Note composer, Properties view, File recovery — встроенные компоненты.

- Vault: Markdown, вложения, YAML properties, .base, JSON Canvas.
- Properties: text, list, number, checkbox, date, datetime, tags.
- Wikilinks, aliases, embeds, block links, callouts, Markdown tasks.
- Навигация: Search, Backlinks, Outgoing links, Graph, Outline, Bookmarks, Quick switcher, Command palette.
