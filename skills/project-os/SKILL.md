# Project OS (Obsidian Project OS)
Универсальная операционная система проекта на базе Obsidian Vault для AI-агентов.
## Маршрутизация скиллов
- Инициализация: `project-init` (`project init`)
- Задачи и Kanban: `project-tasks` (`project task create|start|complete`)
- Память и фокус: `project-memory` (`project memory checkpoint`)
- Контекст сессии: `project-context` (`project context brief|task|topic|full|resume`)
- База знаний и ADR: `project-knowledge` (`project knowledge search`)
- Синхронизация кода и документации: `project-knowledge-sync` (`project knowledge sync`)
- Диагностика целостности: `project-doctor` (`project doctor`)
