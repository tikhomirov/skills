# Project Knowledge Sync
Команда: `project knowledge sync [TASK-ID]`.
Шаги:
1. Получить активную задачу из NOW.md или аргументов
2. Зафиксировать текущий Git commit и diff
3. Проверить затронутые части системы и обновить подтвержденные факты в knowledge/
4. Перевести `knowledge_sync: synced` в задаче и зафиксировать запись в журнале реализации
