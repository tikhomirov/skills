# Рабочая зона _agents и память между сессиями

- `_agents/Memory/NOW.md`: текущая задача, ограничения и следующий шаг. Короткий рабочий фокус, не история переписки.
- `_agents/Memory/STATE.md`: сводка открытых задач. Генератор обновляет раздел «Задачи», остальные разделы агент ведёт самостоятельно.
- `_agents/Memory/sessions/`: передачи контекста между сессиями.
- `_agents/Knowledge/`: исследования, карта проекта, таймлайн решений, ссылки на код и пользовательскую документацию. Карта не должна превращаться в несанкционированную правку модулей.
- `_agents/Reports/`: результаты задач, проверки, ограничения и предложенные изменения документации.

В `_agents/` агент может создавать дополнительные рабочие папки и заметки по необходимости. Например, Skills/ для указателей на используемые скиллы. Активные процедурные скиллы устанавливает skills-install в каталоги ассистентов; не создавать конкурирующие копии правил.

```bash
obsidian-project-framework checkpoint "Сделано: API входа. Осталось: UI. Проверки: npm test passed. Разрешения на правку документации нет. Следующий шаг: TASK-002."
```

Сначала обновить NOW и STATE. Команда сохраняет сообщение, снимки памяти и Git HEAD. Повтор тех же данных возвращает прежнюю сессию, без дубля и новых дат. При изменении контекста создаётся новая запись. Dry-run не пишет ничего.
