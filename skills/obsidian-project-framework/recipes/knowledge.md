# Поиск знаний

```bash
obsidian-project-framework knowledge search "авторизация"
```

Искать по именам и содержимому Markdown в проектной базе: правила, задачи, компоненты, API, решения, память, знания и отчёты. Вложения и служебные скрипты не являются источником проектных знаний.

Результат поиска — указатель, не доказательство. Прочитать заметку, проверить `status`, `review`, `updated` и `sources`. `draft`/`pending` не выдавать за принятое решение. Проверенные факты связать с кодом, не копировать целиком в несколько заметок.
Команда только читает состояние и идемпотентна. Для поиска средствами самого Obsidian и синтаксиса запросов использовать скилл obsidian.
