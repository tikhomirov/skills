# Неразрушающий импорт

```bash
obsidian-project-framework migrate --dry-run
obsidian-project-framework migrate
```

Скрипт только копирует Markdown из docs/ в `_agents/Knowledge/Импорт/` с сохранением вложенных путей. Повтор пропускает существующие назначения и не удаляет источники. Это не автоматическая миграция модулей, решений или произвольной структуры существующего проекта.

Для полноценного переноса сначала исследовать правила/генераторы, предложить карту соответствий и получить согласие. Состав и расположение модулей определяет пользователь. В их документацию без явной просьбы не писать. Решения переносить добавлением исторических событий с реальными источниками/датами, не редактировать и не удалять прошлые записи.
Старые Agents/, AGENT/, HUMAN/, Memory/, Knowledge/, Отчеты/ не удалять молча. После импорта проверить свойства, ссылки и индексы; не повышать неподтверждённые материалы до approved/canonical.
