# Реестр статусов

`_statuses.md` в корне — единственный источник значений, ролей и порядка колонок. Читать перед каждой операцией с задачами; не брать список из памяти/констант.

Файл содержит **только заголовок и таблицу**, без инструкций и примеров:
```markdown
# Статусы задач
| status | Название | Роль | Описание |
|---|---|---|---|
| backlog | Backlog | backlog | Запланировано. |
| in-progress | In Progress | active | В работе. |
| done | Done | done | Завершено. |
```

- status: уникальные строчные латинские буквы, цифры, дефисы; используется в свойствах, имени и теге. Колонка подписана этим значением.
- Роли backlog/active/done: не начато/работа/завершено. Каждая роль должна присутствовать. Create/start/complete выбирают первый статус соответствующей роли; task status — указанный.
- Порядок строк задаёт колонки; название/описание поясняют смысл. Пользователь может добавлять/переименовывать/переставлять статусы; агент — только по его просьбе.
- Для переименования/удаления: сначала добавить новые значения, согласовать соответствие, перевести задачи, затем убрать старые. Неизвестные значения не угадывать.
- После правки: task sync, затем doctor. Init создаёт отсутствующий реестр, но не перезаписывает существующий даже с --force.
