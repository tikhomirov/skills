# Obsidian Skill

Единый скилл для работы с Obsidian: организация баз знаний, базы данных .base, форматирование Markdown и автоматизация через CLI.

## Архитектура рецептов (наподобие Dandy Style)
Не загружай всё сразу. Используй [recipe-map.md](recipe-map.md) для выбора конкретного рецепта под задачу:
- **Базы данных и таблицы:** `recipes/bases.md` — синтаксис .base, фильтры, карточки, формулы.
- **Markdown и метаданные:** `recipes/markdown.md` — вики-ссылки, свойства (Properties), коллауты, встраивания.
- **Консоль и автоматизация:** `recipes/cli.md` — команды Obsidian CLI (`obsidian create`, `property:set`, `tasks`).
- **Справочники синтаксиса:** `references/` — формулы Bases, официальный YAML-спецификатор, канбан-доски.

## Порядок работы
1. Уточни корень vault, прочитай AGENTS.md и правила хранилища.
2. Находи оригиналы, зеркала и генераторы. Изменяй источник, а не сгенерированную копию.
3. Сохраняй валидный YAML Frontmatter в заметках и проверяй синтаксис баз данных перед сохранением.
4. При работе с CLI учитывай, что экземпляр Obsidian должен быть запущен.
