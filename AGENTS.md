# Agent Skills Collection

## Карта
- `skills/` — источники скиллов; `obsidian` — инструменты, `obsidian-project-framework` — процесс, `project-workshop` — диалог, `improvement` — безопасные улучшения.
- `bin/` — только исполняемые входы; `src/` — реализация; `tests/` — проверки.
- `src/obsidian-project-framework/{paths,templates,statuses}.mjs` — структура, генерируемые инструкции, реестр.

## Правила
- Отвечать кратко по-русски. Перед/после правок применять improvement; рекомендации проверять, диапазон не расширять без необходимости.
- При изменении контракта согласованно обновлять код, скиллы, шаблоны, README и тесты. Инструкции короткие, однозначные, без личных путей/проектов; подробности — в рецептах.
- Команды идемпотентны; неизменившиеся файлы не переписывать. Dry-run не создаёт даже каталоги/lock.
- Правила фреймворка — в его SKILL.md: _agents — рабочая зона, модули — read-only без явной просьбы, Решения — append-only.
- _statuses.md — короткий источник статусов; ручной status с доски приоритетнее имени/тегов. Task sync не отменяет решение человека; отметка Done не доказывает проверки.
- Активного индекса нет; канбан — _Задачи.base, архив — _archive с табличной БД и индексом. Не переиспользовать ID.
- Секреты не копировать. Живые проекты/Vault менять только по поручению, с резервной копией. Миграция не удаляет историю. Коммит/push — только по разрешению.

Проверки: `make check`, `make test`, `make help`. Тесты — во временных каталогах, не в пользовательских проектах.
